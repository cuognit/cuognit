## About me

Hi, I'm **Nguyễn Mạnh Cường** (cuognit), a final-year Software Engineering student focused on backend engineering and full-stack development.

I enjoy building applications from API and data layers through to the user interface. My projects have given me hands-on experience with e-commerce workflows, real-time messaging, authentication, payment integration, and AI-powered features.

- **Backend:** Node.js, Express, Java, Spring Boot
- **Frontend:** React, TypeScript, Vite, Tailwind CSS
- **Data:** MongoDB, PostgreSQL, Redis
- **Interests:** API design, application security, real-time systems, asynchronous processing, applied AI

## Featured projects

### 🛍️ [AI-Powered Fashion E-commerce](https://github.com/cuognit/AI-Powered-Fashion-E-commerce)

A full-stack fashion commerce platform combining shopping workflows, administration tools, and AI-powered discovery.

- Product catalog with variants, filtering, search, cart, wishlist, and order tracking
- JWT authentication with role-based access for Admin, Staff, and Customer
- VNPay and cash-on-delivery checkout, plus an admin dashboard for orders and analytics
- Gemini fashion chatbot with streamed responses, embeddings, and MongoDB Atlas Vector Search
- AI virtual try-on and image uploads through Cloudinary

**Stack:** React 19, Vite, Tailwind CSS, Express, MongoDB, Mongoose, JWT, Google Gemini, SSE, Cloudinary, VNPay

---

### 💬 [HoLaChat](https://github.com/cuognit/HoLaChat)

A real-time messaging application with a Spring Boot backend and React frontend.

- Real-time conversations using WebSockets and STOMP
- Private chats, chat rooms, and online/offline presence
- JWT and refresh-token authentication, with email OTP for password recovery
- Redis-backed message and presence workflows, with PostgreSQL persistence
- Responsive interface with deep links to chat rooms

**Stack:** Java 21, Spring Boot, Spring Security, WebSocket, STOMP, PostgreSQL, Redis, React 19, Vite

---

### 🎵 [WebMusic](https://github.com/cuognit/WebMusic)

A full-stack music streaming application with a public deployment.

- Music streaming, favorites, and listening history
- Admin dashboard for song management and listening analytics
- Account authentication, password hashing, rate limiting, and session management
- Backend organized around background workers and job queues

**Stack:** Node.js, Express, MongoDB, Mongoose, Handlebars, SASS, Redis

[**Try the live demo →**](https://webmusic-7vy8.onrender.com)

---

### 📦 [Project_Int — Order Management](https://github.com/cuognit/Project_Int)

A React and Express order-management application with a separate backend API and an admin account.

**Stack:** React, Vite, Tailwind CSS, Express, JavaScript
